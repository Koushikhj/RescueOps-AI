# RESCUEOPS AI
### Multi-Agent Emergency Response Coordinator

RescueOps AI is an AI-powered emergency response coordination platform designed to help manage emergency situations through intelligent multi-agent collaboration.

## Project Vision
To improve emergency response coordination by connecting emergency reports, intelligent analysis, resource allocation, and response planning.

## Technology Stack
- Frontend: React.js + Vite
- Backend: Node.js + Express.js
- AI Service: Python + FastAPI
- AI Integration: LLM APIs
- Database: MongoDB
- Version Control: Git & GitHub

## Frontend Setup

1. Clone the repository.
2. Install dependencies:

   npm install

3. Start the development server:

   npm run dev
